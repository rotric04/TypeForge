# Security Policy

This document outlines the security disclosure process for my profile repositories and open-source projects, including **TypeForge AI**.

I take the security and integrity of my applications and open-source tools seriously. If you have discovered a vulnerability, please read this policy to report it responsibly.

## Supported Versions

Only the latest release versions of my projects are actively supported with security patches:

| Project | Supported Versions | Status |
| ------- | ------------------ | ------ |
| **TypeForge AI** | `main` branch (latest production release) | :white_check_mark: Supported |
| Other repositories | Latest tagged release | :white_check_mark: Supported |
| Legacy/Archived | Any version | :x: Not Supported |

## Reporting a Vulnerability

**Please do not open public issues on GitHub for security vulnerabilities.**

Instead, please report security issues privately:

1. Email me directly at **[mohitassudani.3@gmail.com](mailto:mohitassudani.3@gmail.com)**.
2. Provide a detailed summary of the vulnerability, including:
   - Affected repository/service name.
   - A step-by-step description of how to reproduce the issue.
   - Potential impact of the exploit.
   - Any suggested remediation or patches if available.

### What to Expect

* **Response Time**: I will acknowledge receipt of your vulnerability report within **48 hours** and provide an initial assessment of the issue.
* **Remediation**: If the vulnerability is verified, I will prioritize a fix and aim to release a patch or release a statement within **14 days**.
* **Attribution**: Once fixed, if you wish, I will credit you in the release notes for discovering and reporting the issue responsibly.

Thank you for helping keep my open-source projects safe!
