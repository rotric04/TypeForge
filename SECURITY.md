# Security Policy

## Supported Versions

Only the latest release version on the `main` branch of TypeForge AI is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main (production) | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please do not open public GitHub issues for security vulnerabilities. 

If you discover a security issue, please report it privately:
1. Email the maintainer directly at **[mohitassudani.3@gmail.com](mailto:mohitassudani.3@gmail.com)**.
2. Provide a description of the vulnerability, step-by-step instructions to reproduce it, and its potential impact.

I will acknowledge receipt of your report within 48 hours and aim to resolve confirmed issues within 14 days.
